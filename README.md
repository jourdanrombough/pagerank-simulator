# PageRank Simulator: See How Link Juice Flows

An interactive link graph simulator. Build links between pages and watch PageRank flow in real time. Test private blog networks, link farms and parasite pages, then run a SpamBrain-style sweep to see which link schemes get caught.

**Live demo:** https://jourdanrombough.github.io/pagerank-simulator/
**Published on:** https://optimizationtheory.com/pagerank-simulator-see-how-link-juice-flows-interactive/

## What you can do

- Add pages and links and watch authority redistribute with each iteration
- See how damping, outbound link count and internal linking change the result
- Model common manipulation patterns (PBNs, link farms, parasite pages)
- Run a detection sweep to see which schemes a spam classifier would likely flag

## Built with

HTML, CSS and vanilla JavaScript running the PageRank iteration in the browser. No frameworks and no build step. Open `index.html` to run it locally.
